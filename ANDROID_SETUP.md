# Matayia's Welfare — Android App

This project is prepared to package the existing React/Vite welfare app as an Android application using Capacitor 8.

## What stays the same

- Existing Supabase project and database
- Member/Admin login
- Members, contributions, Table Banking
- Merry-Go-Round and Sugar summaries
- Loans and repayments
- Events, attendance, announcements and minutes
- Admin dashboard

The Android app is a native Android container around the same web application, so it does not create a second database.

## Build on a computer

Requirements:
- Node.js 20+
- Android Studio with an Android SDK installed
- Java/JDK compatible with the installed Android Studio/Gradle setup

Then run:

```bash
npm install
npm run android:add
npm run android:sync
npm run android:open
```

Android Studio will open the generated `android` project. Use its Build/Run tools to test on a phone or emulator.

For a debug APK from the command line:

```bash
npm run android:build
```

The debug APK will normally be under:

`android/app/build/outputs/apk/debug/app-debug.apk`

## Important

The `android` folder is generated by Capacitor after dependencies are installed. It is intentionally not included in this prepared source ZIP because the Android SDK/Gradle environment is machine-specific and the current environment cannot reliably compile the native project.
